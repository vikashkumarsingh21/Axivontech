# Chatbot Bug Fix Report

## 1. ROOT CAUSE
The chatbot was constantly returning the initial welcome message ("Hi! Welcome to Axivon Technologies. How can I help you today?") for two critical reasons:
1. **Frontend-Backend Payload Mismatch**: The React frontend (`ChatWidget.tsx`) was sending `{ message: text }` in the JSON body. However, the Next.js API route (`route.ts`) was attempting to destructure `body.messages` array to extract the last user message. Because `body.messages` was undefined, the server evaluated the user message as an empty string `""`.
2. **Hardcoded Fallback Triggered**: When the API route evaluated the message as an empty string, it immediately hit this fallback condition:
   `if (!lastUserMsg.trim()) return "Hi! Welcome..."`
   Because every request was empty, it constantly repeated the exact same welcome message.
3. **Missing Conversation ID**: The frontend was not saving or sending the `conversationId` generated by the backend. This meant that every single request was treated as a brand new chat session with no memory, completely destroying conversation context.

## 4. ROOT CAUSE FIX
- **Frontend Payload Update**: Modified `ChatWidget.tsx` to properly read `data.conversationId` from the backend's response and inject it into the payload on subsequent requests.
- **Backend Parsing Fix**: Modified `route.ts` to actively check for `typeof body.message === "string"` to safely extract the user's input, while maintaining backward compatibility with the `body.messages` array approach.

## 5. API FLOW
**User sends message:** "I need auto website development"
**Frontend (`ChatWidget.tsx`)**: 
   → Captures text, appends `conversationId` (if active)
   → Calls `fetch('/api/chat', { method: 'POST', body: JSON.stringify({ message: text, conversationId: "abc" }) })`
**Backend (`route.ts`)**: 
   → Safely extracts `body.message`
   → Injects string into `generateResponse()` alongside `conversationId` session memory
**AI (`ai-engine.ts`)**: 
   → Model receives the exact message text and previous context
**Response**: 
   → Backend parses the AI answer and updates the conversation state.
**Frontend (`ChatWidget.tsx`)**: 
   → Renders the true generated message.
